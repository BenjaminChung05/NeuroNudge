# NeuroNudge

**Status: Planning**

NeuroNudge is a proposed EEG-based student attention monitoring system for the EIRP project. It explores whether experimental EEG-derived engagement trends can support personalised learning. The system is not a medical or diagnostic device, and an estimated change in attention does not by itself establish that a student is distracted.

## Proposed architecture

TGAM EEG headband → ESP32-S3 → laptop for signal processing → cloud database → web dashboard

The proposed laptop software will process the EEG signal and estimate attention trends. A login-protected dashboard is planned to show those trends and alerts to authorised adults. Hardware, software, testing and integration are still planned; details may change as the team assesses feasibility.
